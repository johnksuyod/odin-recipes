# Odin Recipes

A basic recipe website built as part of The Odin Project's Foundations Course.

## About The Project

This project is my first foray into building a complete, multi-page website using pure HTML. It consists of a main index page that links out to three recipes. Each recipe page features an image of the finished dish, a brief description, an unordered list of ingredients, and an ordered list of step-by-step instructions.

## Skills Demonstrated & What I Learned

By completing this project, I practiced and demonstrated the following core web development skills:

- **HTML Boilerplate:** Setting up the foundational structure of an HTML document (`<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`).
- **Text Formatting:** Organizing content semantically using headings (`<h1>` through `<h6>`) and paragraphs (`<p>`).
- **Lists:** Utilizing unordered lists (`<ul>`) for ingredients and ordered lists (`<ol>`) for sequential cooking steps.
- **Links & Navigation:** Creating relative links (`<a>`) to connect the main `index.html` page with individual recipe pages stored within a `recipes/` directory.
- **Images:** Embedding images (`<img>`) and providing descriptive `alt` attributes for better web accessibility.
- **Git Workflow:** Practicing basic terminal commands, staging files, writing meaningful commit messages, and pushing local code to a remote GitHub repository.
